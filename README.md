# Machine Learning 2026

## Project Overview
This repository contains laboratory work for the Machine Learning course. The semester-long dataset utilized is the Olist Brazilian E-Commerce Public Dataset.

## Folder Structure
* `data/raw/`: Original dataset files (Excluded from Git tracking)
* `data/processed/`: Cleaned and transformed datasets
* `notebooks/`: Jupyter notebooks for exploratory analysis and experiments
* `src/`: Reusable Python source code scripts
* `reports/`: Documented summaries, analysis, and data dictionaries
* `figures/`: Generated data visualizations and plots
* `models/`: Trained model binaries and checkpoints

## Lab 1
Lab 1 focuses on development environment setup, dataset loading, initial structural analysis, data profiling (missing values and duplicates), and preliminary exploratory data analysis (EDA).
